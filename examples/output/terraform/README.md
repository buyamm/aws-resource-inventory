# Terraform

Generated by AWS Resource Inventory from the collected specifications (`aws-inventory
generate-iac`). Every resource block names its source specification file and ARN.

| Directory | Contents |
|---|---|
| `modules/iam/` | IAM roles with their attached and inline policies |
| `modules/observability/` | CloudWatch log groups |
| `modules/network/` | VPCs, subnets, route tables, internet and NAT gateways, VPC endpoints, security groups and their rules |
| `modules/edge/` | Route 53 zones, ACM certificates, WAF web ACLs, CloudFront and load balancers |
| `modules/data/` | S3 buckets, DynamoDB tables, RDS instances, ElastiCache, SQS queues and SNS topics |
| `modules/compute/` | ECR, launch templates, Auto Scaling groups, EC2 instances, ECS, Lambda, Step Functions, EventBridge rules and schedules |
| `envs/default/` | Root configuration: modules, providers, S3 backend, `imports.tf`, `verify_state.sh` |

Each module has `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf` and a `README.md`.
References between resources use Terraform expressions; a resource of another module is
reached through that module's outputs, wired in `envs/default/main.tf`.

## Import the existing resources

```bash
cd envs/default
terraform init -backend-config="bucket=<state bucket>" \
  -backend-config="key=default/terraform.tfstate" -backend-config="region=us-east-1"
terraform plan       # expected: N to import, 0 to add, 0 to change, 0 to destroy
terraform apply      # records the imports in state; nothing else changes
./verify_state.sh    # exit 0 = configuration matches AWS
```

Values the collector could not read (redacted secrets, Lambda code, the RDS master
password) are marked `# REDACTED: set manually` or listed in `lifecycle.ignore_changes`.
